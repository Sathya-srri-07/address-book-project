FEATURES

Everything a contact list needs, nothing it doesn't.

ADD

Guided entry

Name, phone, email, address, and notes — validated as you type, with duplicates caught before they're saved.

FIND

Instant search

Filter by name, phone, or email as you type, grouped alphabetically like a real card drawer.

EDIT

Edit in place

Open any card, change what's needed, save — no separate edit screen to get lost in.

SORT

Sort & favorite

A–Z, Z–A, or most recent, plus a star for the contacts you reach for most.

MOVE

Import & export

Back up the whole book as JSON, or hand off one card as a standard .vcf file.

KEEP

Never lose data

The C++ version writes to disk on every change; the web app autosaves locally the same way.
